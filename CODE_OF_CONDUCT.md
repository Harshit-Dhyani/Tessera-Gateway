# Code of Conduct

## Our Standard

Tessera Gateway is built around careful technical work and direct feedback. Be
clear, respectful, and useful when discussing bugs, security concerns, design
tradeoffs, and provider breakage.

Good participation includes:

- focusing on the issue and evidence
- giving reproducible details
- accepting correction when new facts appear
- avoiding personal attacks, harassment, or dismissive behavior
- protecting private data and account details

Unacceptable behavior includes:

- harassment or discrimination
- threats or personal insults
- publishing private information without permission
- knowingly sharing secrets, credentials, tokens, or replayable session data
- encouraging bypasses of provider consent, login challenges, or security controls

## Enforcement

Maintainers may remove comments, close issues, block users, or reject
contributions that violate this code. Serious security or privacy violations may
be handled immediately to protect users.

## Scope

This code applies to repository issues, pull requests, discussions, reviews, and
project communication spaces.
